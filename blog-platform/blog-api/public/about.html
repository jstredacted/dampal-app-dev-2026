Ateneo Times

A satirical campus blog

About

The Ateneo Times is a satirical campus blog, written somewhere between the last class and the next deadline. It is a class project and not a real newspaper.

This blog runs on two Express servers. The Auth Server creates accounts and gives out login tokens (JWTs). The Blog API stores the blogs and checks those tokens by itself.

Anyone can read blogs without logging in.

  • Readers can read blogs and see their own (empty) blog list.
  • Authors can write blogs and edit their own.
  • Admins can write blogs, edit any blog, and delete blogs.
